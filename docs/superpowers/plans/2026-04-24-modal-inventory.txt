Step 0.4 — WHY THE ORIGINAL SWEEP MISSED 3 DECLARATIONS (post-commit supplemental):

  Root cause: Step 0.2 used same-line grep patterns combining selector + width on one line.
  CSS multi-line rule bodies (selector on line N, width: on line N+2) are invisible to
  same-line grep. The three missed rules all follow the pattern:

    .selector-name {          ← line N   (grep key)
        position: ...;        ← line N+1
        width: min(Xpx, ...); ← line N+2 (NOT matched — not on same line as selector)

  The correct grep form is grep -A <n> to emit context lines after the selector match,
  then pipe through a second grep for the width pattern.
