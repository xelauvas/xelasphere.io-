For: "write a function", "fix this bug", "explain this code", "what does X mean in [language]"

Throttle a function in JS

Wrap the call so it runs at most once per delay ms:

function throttle(fn, delay) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= delay) {
      last = now;
      fn(...args);
    }
  };
}
⚠️ Edge case: trailing call is dropped. Use debounce if you need it.
