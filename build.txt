4) Assistant → App contract (CRITICAL)

The assistant must emit artifacts in one strict format.

Artifact block format

The assistant outputs exactly one fenced block:

```artifact
{
  "title": "Project Name",
  "entrypoint": "README.md",
  "files": [
    {
      "path": "README.md",
      "language": "markdown",
      "content": "# Project\n..."
    },
    {
      "path": "src/main.py",
      "language": "python",
      "content": "print('hello')"
    }
  ],
  "meta": {
    "runtime": "python",
    "run": "python src/main.py"
  }
}


### Parsing rules
- Artifact block **must be valid JSON**
- No text before or after the block
- Reject paths containing `..` or absolute paths
- Enforce max size limits (files + total bytes)
- Enforce unique file paths

### Behavior
- If an artifact exists for the chat → create a new version
- If none exists → create artifact + version v1
- Parsing failures must NOT break chat UI
